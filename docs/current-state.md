# Current state

Version 2 is an advertising-only Hermes autopilot: official Amazon MCP capability discovery, deterministic sponsored-ads planning, Executor-only atomic writes, independent Verifier read-back, Marketing Stream alert ingestion and a simple Web control surface.

Default mode is `observe` and execution is disabled. Production acceptance still requires the owner’s OAuth and Amazon Ads Test Account or real profile. No Seller Central browser automation or non-advertising business operation is included.
